## Reproduce

Use a disposable PostgreSQL database and simulation mode:

```sh
npm ci
cp .env.example .env
npx drizzle-kit push --force
npx tsx --test tests/domain.test.ts tests/release.test.ts
npx next typegen
npm exec tsc -- --noEmit --pretty false
npm run build
NODE_ENV=production npx tsx server/index.ts
# In another terminal:
BASE_URL=http://127.0.0.1:3000 node tests/smoke.mjs
npx tsx scripts/package-release.ts
npx tsx scripts/verify-release.ts
npm audit --omit=dev
```

The smoke script refuses non-simulation mode and restores the three affected catalog items in `finally`. It is not a real PayPal integration test. See `SUBMISSION.md` for the remaining competition requirements.
